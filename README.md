# Dark Glass Music Player

Тёмный полупрозрачный музыкальный плеер для Windows 11 на Python (PySide6).

## v4.1 — YouTube без браузера (для слабых ПК)

Вкладка YouTube в Chrome/Edge легко занимает 1.5–3 ГБ RAM. Рядом лежит скрипт
`youtube_lite.py`, который играет те же видео через **mpv + yt-dlp**
(~150–400 МБ, без рекламы и фоновых процессов), с жёстко ограниченным буфером
плеера.

```powershell
winget install yt-dlp mpv Gyan.FFmpeg
python youtube_lite.py --check                      # проверка окружения
python youtube_lite.py https://youtu.be/VIDEO_ID    # смотреть
python youtube_lite.py "lofi hip hop" --quality low # поиск + 360p (минимум RAM)
python youtube_lite.py URL --audio                  # только звук
python youtube_lite.py --gui                        # окно-пульт
```

Если YouTube смотрится в Firefox — там же лежит `firefox_tune.py`, который
записывает в профиль настройки памяти (`user.js` с резервной копией):

```powershell
python firefox_tune.py --list                 # профили Firefox
python firefox_tune.py --print --preset 8gb   # что будет записано
python firefox_tune.py --apply --preset 8gb   # применить (8 ГБ RAM)
python firefox_tune.py --remove               # откатить
```

Подробный чек-лист «что делать, если YouTube съедает всю память» (Firefox,
Chrome/Edge, Windows, диагностика утечек) — в
[`docs/YOUTUBE_RAM_RU.md`](docs/YOUTUBE_RAM_RU.md).

Зависимость необязательная: сам плеер (`music_player.py`) работает без
`yt-dlp`/`mpv`, они нужны только для YouTube Lite:
`pip install -e ".[youtube]"`.

## v4.0 — Блок 1: аудио-движок (готово)

Реализовано и полностью рабочее:

- **10-полосный эквалайзер** (`🎛 Эквалайзер` на экране «Сейчас играет») —
  реальные полосовые (peaking) биквад-фильтры, применяются к звуку "на лету"
  во время воспроизведения. Пресеты: Rock, Pop, Bass Boost, Jazz, Flat,
  Custom (переключается автоматически при ручной подстройке).
- **Настоящий FFT-визуализатор** — спектр считается из реального
  воспроизводимого сигнала (`numpy.fft`), а не имитируется. Если по какой-то
  причине звук не удалось декодировать, визуализатор мягко откатывается на
  прежнюю анимацию, а не ломает интерфейс.
- **Скорость воспроизведения 0.5x–2.0x** (выпадающий список рядом с
  кнопкой эквалайзера) — реализована через тайм-стретчинг (`librosa`), тон
  не искажается. Если `librosa` не установлена — скорость всё равно
  работает, но через ресемплинг с небольшим изменением высоты тона (это
  указано в `requirements.txt`).

Технические детали и известные ограничения — в `audio_engine.py` в докстринге
модуля (декодирование через `pydub`+`ffmpeg`, `QAudioSink` в pull-режиме,
обработка DSP синхронно на CPU).

## v4.0 — Блок 2: все остальные функции ТЗ (готово)

Реализовано:

- **Темы оформления** — 12 готовых тем (`🎨 Тема`: Dark Glass, Neon Green,
  Crimson Ember, Ice Blue, Midnight Rose, Sunset Gold, Ocean Deep, Lavender,
  Cherry Blossom, Emerald, Midnight Blue, Copper), задаются в
  `styles/theme_qss.py` (единый источник `THEME_PARAMS` — из него строятся и
  QSS, и акценты в настройках) и переключаются на лету, выбор сохраняется
  между запусками.
- **Компактный PiP-режим** — `MiniPipWidget`, всегда поверх окон.
- **Анимации переходов** — плавное появление/скрытие окна, fade между
  экранами «Плейлист» / «Сейчас играет».
- **Сохранение/загрузка плейлистов** — сессия в `config.json` (автоматически)
  и импорт/экспорт `.m3u8` (кнопка `💾 M3U8`).
- **Сортировка** — по названию или исполнителю (`⇅ Сортировка`).
- **Избранное** — сердечко на карточке трека / в контекстном меню.
- **Автопоиск обложек и текста песен онлайн** — если в файле нет встроенной
  обложки или текста, плеер в фоне обращается к публичному iTunes Search API
  (обложки) и LRCLIB (тексты) через `online_services.py`.
- **Редактор тегов** — `TagEditorDialog`, правка названия/исполнителя/альбома.
- **Глобальные хоткеи** — системные мультимедиа-клавиши (Play/Pause, Next,
  Prev, Stop) работают даже когда окно не в фокусе (только Windows, через
  `RegisterHotKey`/`WM_HOTKEY`).
- **Таймер сна** — плавное затухание громкости и пауза через 15/30/60 минут
  (пункт в трее и в интерфейсе).
- **Интернет-радио** — кнопка `📻 Радио`, список проверенных потоковых станций
  (SomaFM, Radio Paradise, KEXP, NPO 3FM, Radio Swiss Classic — каждый URL
  проверен перед добавлением), воспроизведение через отдельный `QMediaPlayer`
  (потоковое аудио не декодируется локальным DSP-движком, в отличие от файлов);
  при недоступности потока выводится уведомление, а не ложное «Playing».
- **Discord Rich Presence** — показывает текущий трек в статусе Discord;
  включается/выключается из трея; настоящий Application ID задаётся в
  настройках (без него подключение просто не выполняется); если `pypresence`
  не установлена или Discord недоступен — тихо отключается, ничего не ломая.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python music_player.py
```

## Тесты

```bash
python -m pytest tests
```

Тесты покрывают DSP-ядро (эквалайзер, реверберация, кэш), онлайн-службы
(валидность URL радиостанций) и темы оформления (полнота акцентов).

## Возможности

- Тёмная тема + настоящий эффект размытия фона (Acrylic), как в приложениях Windows 11
- Своя рамка окна без стандартного заголовка (перетаскивание за верхнюю панель)
- **Плейлист карточками**: у каждого трека — миниатюра обложки (или стильная заглушка), жирное название и серый исполнитель, с аккуратными скруглениями и подсветкой при наведении
- **Экран "Сейчас играет"**: отдельная полноэкранная панель с крупной обложкой (с мягкой тенью), крупным названием/исполнителем, слайдером перемотки и центральными кнопками управления — открывается двойным кликом по треку или через мини-плеер
- **Мини-плеер**: компактная панель внизу плейлиста с текущим треком, play/pause и переходом к следующему треку; клик по ней разворачивает экран "Сейчас играет"
- Добавление треков через кнопки "+ Файлы" / "+ Папка" или перетаскиванием (drag & drop)
- Play / Pause / Стоп (авто) / Следующий / Предыдущий
- Перемешивание (shuffle) и повтор (весь плейлист / один трек)
- Показ текста песни (метаданные USLT / .txt / .lrc файлы) — переключается кнопкой на экране "Сейчас играет"
- Поиск по плейлисту (по названию и исполнителю)
- Горячие клавиши: Space (play/pause), ←/→ (перемотка), ↑/↓ (громкость), F11 (полноэкранный режим), Esc (выход из полноэкранного режима или возврат к плейлисту)
- Системный трей с уведомлениями о смене трека
- Анимированный аудио-визуализатор на экране "Сейчас играет"
- Поддержка форматов: mp3, wav, flac, m4a, ogg, wma, aac

## Заметки

- Эффект Acrylic работает только на Windows (10/11); на других ОС окно будет просто тёмным и полупрозрачным без blur.
- Если обложка не отображается — значит, в файле нет встроенной картинки; вместо неё показывается фирменная заглушка с нотой.
- Окно можно свернуть и закрыть кнопками в правом верхнем углу; перетаскивание — за верхнюю панель; двойной клик по верхней панели тоже переключает полноэкранный режим.
